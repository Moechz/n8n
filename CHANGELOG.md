# Changelog

All notable user-visible changes to the n8n Workflow Automation TOS application package.

## 2.41.3-1 — 2026-09-27

### Added
- First release. n8n Workflow Automation (`n8nio/n8n:2.41.3`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8001 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/n8ndocker/`.
